## R1 - Game research
Game: Five Nights at Freddy's (FNAF 1)

Goal: The goal is to survive five nights as a security guard at Freddy Fazbear's Pizza. I have to survive until 6 AM each night without getting caught by the animatronics.

Player action: I can check the security cameras to see where the animatronics are. I can also turn on the hallway lights and close the security doors to protect myself. I have to manage my electricity because using these controls drains power.

Feedback: The game shows the security camera views, the positions of the animatronics, and the remaining power. I can also hear sounds and see visual changes when the animatronics move or approach the office. If I survive until 6 AM, I complete the night. If an animatronic catches me, a jumpscare appears and I lose.

Source: https://store.steampowered.com/app/319510/Five_Nights_at_Freddys/

## R2 - Three engines and my choice
1. Godot: Godot supports both 2D and 3D games. It uses GDScript and C# for programming. One useful feature is its node and scene system, which helps organize game objects. I would use Godot to create the office, doors, cameras, and animatronics for a horror game like FNAF 1. [https://docs.godotengine.org/en/latest/](https://docs.godotengine.org/en/latest/)

2. Unity: Unity supports both 2D and 3D games and uses C# for programming. It uses GameObjects and components to create and control game objects. I could use Unity to create animatronics, security cameras, and interactive doors for a game like FNAF 1. [https://docs.unity.com/](https://docs.unity.com/)

3. Stride: Stride is a game engine focused on 3D game development and uses C# for programming. It uses entities and components to organize game objects. I could use Stride to create a 3D horror game with an office, animatronics, and interactive objects. [https://doc.stride3d.net/latest/en/](https://doc.stride3d.net/latest/en/)
